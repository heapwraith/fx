Search

Find any file as you type.

Ctrl F searches this folder and everything inside it. Tab switches to the whole disk, which Pathdash reads straight from the NTFS MFT.

  • Filters that combine with the name: type:image, size:>100mb, date:week, tag:green
  • content:"invoice" looks inside the files
  • Ctrl S saves the search, and it keeps itself up to date

Keyboard first

Every command, one Ctrl K away.

The palette finds any action or folder by name and learns the folders you open most. Each command shows its shortcut, so next time you will not even need it.

  • Explorer shortcuts work the same: F2, Alt Enter, Ctrl Shift N
  • Built-in terminal on Ctrl J, following the open folder

How it works

Why whole-disk search is instant.

Explorer searches by opening folder after folder. Pathdash reads the table NTFS already keeps.

Reads the MFT

An optional service reads the NTFS file table in one go, in seconds, instead of visiting millions of folders.

Follows the journal

Through the Windows USN journal, every file created, renamed or deleted reaches the index at once, with no rescan.

Answers per key

Every letter you type is a fresh search in memory: about 5 ms, even with 2 million files.

Questions

Before you download

Is it free?

Yes, and open source (MIT or Apache-2.0). There is no paid version and no account to create.

Does it replace Explorer?

Only if you want it to. In Settings › System, "Use Pathdash" makes folders, drives and Win+E open in it; "Back to Explorer" restores exactly what was there. Otherwise the two live side by side.

Why does Windows say "unknown publisher"?

Pathdash is not code-signed yet (it is in progress). Click "More info", then "Run anyway". Installers downloaded by the updater are checked against the SHA-256 published with each release.

Does it need administrator rights?

Not to install or use it: it installs for your user only. Only whole-disk search, which is optional, asks once to install the service that reads the MFT.

Does it run on ARM PCs?

Yes. Every release has x64 and ARM64 installers, and this page downloads the right one for your PC.

How does it update?

Once a day it looks for a new version on GitHub, downloads and checks it in the background, and installs it when you close the app. You can turn this off in Settings › Updates.
